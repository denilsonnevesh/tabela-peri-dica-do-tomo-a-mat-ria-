# Missão: Tabela Periódica V5
Jogo multiplayer em tempo real.
Professor: escolhe Professor, informa nome, cria sala e recebe código.
Aluno: escolhe Aluno, informa nome + código e entra.
Perguntas aparecem no painel do professor e nas telas dos alunos.
O ranking é atualizado em tempo real.

Render:
Build Command: npm install
Start Command: node server.js
Root Directory: vazio.
